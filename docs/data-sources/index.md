# Data sources and rights

Seascape transforms third-party grids and mapped inventories. It does not own the original data. Source versions, acquisition identity, licenses, and coverage should be checked in the selected configuration and resulting manifests before publication or redistribution.

| Source family | Provider and configured dataset | Source support and use | Source record |
| --- | --- | --- | --- |
| Bathymetry | [GEBCO](https://www.gebco.net/data-products/gridded-bathymetry); configured GEBCO 2026 grid | Global 15-arc-second elevation grid; marine pixels become H3 depth statistics at R8/R6. Grid spacing is not accuracy. | [Seafloor source/method guide](https://github.com/MarineCast/toolkit-seascape/blob/main/src/seascape/seafloor_physiography/README.md) |
| Substrate | dbSEABED December 2025 rasters distributed through HUB Ocean | Global 0.1° modeled rock-presence and sediment-texture surfaces; point sampled, then reported on marine H3 support. Exact rights and compatibility of the pinned catalogs require provider review. | [Substrate source note](https://github.com/MarineCast/toolkit-seascape/blob/main/src/seascape/benthic_substrate/classification/DATA_SOURCES.md) |
| Physical shoreline | NOAA/NWFSC 2018 Washington marine shoreline typology; Province of BC ShoreZone units | Jurisdiction-specific mapped segments normalized into physical shoreline classes; source IDs and dates retained. | [Shoreline source note](https://github.com/MarineCast/toolkit-seascape/blob/main/src/seascape/coastal_configuration/shoreline_characterization/DATA_SOURCES.md) |

!!! warning "Coverage and rights are source-specific"
    A source's nominal grid spacing or geographic extent is not its measurement accuracy, local survey completeness, or permission to redistribute derived/source rasters. The GEBCO grid has its own terms and attribution; the toolkit's Apache-2.0 license applies to software. The dbSEABED pinned catalogs need additional line-by-line unit and redistribution review, as recorded in the source note.

Acquisition, normalization, and candidate processing are separate operations. The [stage input reference](../stage-inputs.md) lists configured local prerequisites; [bounded workflow guidance](../WORKFLOWS.md#bounded-real-data-processing) shows how to inspect a small candidate. The release manifest retains source and artifact lineage for the actual run.

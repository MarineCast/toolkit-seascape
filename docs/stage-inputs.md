# Default stage input reference

[Documentation index](README.md) · [Edited-config preflight](WORKFLOWS.md#plan-and-build-a-candidate)

This table is generated from the existing workflow and preflight against packaged default
configuration in a disposable workspace. It lists local prerequisites, not a second planner
or acquisition recipe. `.seascape/docs-preview` paths are candidate-generated dependencies;
raw paths must be provided/reviewed. For edited settings, use your own `--dry-run --check-inputs`.
An empty initialized workspace is expected to fail required input checks.

Source rights, datum, coverage and scientific eligibility are not established by a path declaration.
Read each source's `DATA_SOURCES.md` via the [family guides](products.md#family-guides).
Default bounds can be very large. No download size, performance or regional scaling promise is made;
the measured real-data operating envelope remains the separate SS-10 task.

Maintainers regenerate only this metadata reference with
`python scripts/check_docs.py --write-stage-reference`, then inspect the diff. The checker never
materializes datasets or regenerates the authoritative product catalog. CI checks drift offline.

SEASCAPE ROADMAP
=================

This is the canonical seascape roadmap. Family READMEs link here so feature
status, product contracts, and feature eligibility cannot drift apart.


Completed engineering remediation
---------------------------------

[x] Dependency-aware candidate-first environment orchestration with resume,
    force, dry-run actions, blocked descendants, and terminal release stages.
[x] Journaled family and full-release publication with rollback, recovery,
    manifest-last promotion, global release locking, and snapshot readers.
[x] Manifest schema v3 semantic contracts and independent release checksum audit.
[x] Canonical R8 5 km radius-sum operator and reachable-water-area derivative.
[x] Water-geometry, freshwater-source, and habitat-surface ownership splits;
    compatibility-only wrappers removed and scoped Pyflakes enforced.
[x] All-null and unavailable fields excluded by static feature eligibility;
    alternate physical scales remain discoverable for application selection.


Release gates still required after source or producer changes
-------------------------------------------------------------

[ ] Rebuild the complete family in a disposable output root without downloads or inspectors.
[ ] Compare staged versus current cell hashes, schemas, nulls, QC states,
    categorical counts, distributions, and numeric values; publish the artifact
    release if its audit passes. Alternate scale groups do not block physical
    publication; consumers select scales under their own validation contracts.

Deferred candidates
-------------------

[ ] Shoreline length density and multiscale sinuosity (research-only; non-default).
[ ] Island count, island area, archipelago density, land-water boundary density,
    coastal orientation, and orientation variability.

These remain research-only physical candidates pending explicit product contracts.
Protected areas, critical habitat, and shipping lanes belong in separate owning
roadmaps rather than this remediation.

Blocked
-------

[ ] Estuarine polygon membership and class: BLOCKED until a defensible cross-border
    polygon ontology supports a consistent ecological definition and provenance.

Coarse-first regional scope (completed 2026-10-08)
------------------------------------------------
Plan and acceptance contract: ../../docs/methodology/coarse-v1-plan.md
Historical full-family gates above apply to the completeness claimed by a release;
scoped delivery does not certify the whole catalog.

[x] Retain verified static core, default R6 and supported native R8 companions.
[x] Qualify cached seagrass and dbSEABED exact source rights/units/support;
    retain model composites, unknown observation dates and missingness explicitly.
[x] Publish reviewed native R6 positive-only seagrass with source-rectangle,
    survey/absence and projected-edge qualifications; native R8 remains deferred.
[x] Publish direct R6 coarse modeled substrate with separate rock/sediment bases,
    point masks/availability, conditional entropy and NULL unsupported metrics.
[x] Publish context-gated native R8 terrain-form proxies with explicit heuristic
    thresholds and NULL reasons; preserve Arrow-native source QC missingness.
[x] Publish reviewed static v5 exact joins, all prior values/types/NULLs/order,
    dictionaries, source bindings, sidecars and checksums; no annual duplicates.

Later upgrades and dependencies
-------------------------------
[ ] Consume qualified Hydrology mouth/proximity evidence. River topology,
    drainage, discharge and barriers belong to Hydrology; no Seascape R5 network.
[ ] Native R8 seagrass and native R8 substrate need separate support/method/cost
    qualification; no upsampling. Native R6 terrain classification unsupported.
[ ] Fine coast/islands, observed habitat surveys, measured hardness, passage/sill
    methods and expanded coverage; not gates for the qualified coarse release.
[ ] Qualify DNR SVMP/DFO NETForce/PMEP/DFO Bottom Patches exact rights, vintage,
    measured-versus-modeled support and survey opportunity before acquisition.
[ ] Qualify exact public DFO sponge layer before replacing configured access-only
    source gate; missing ingestion never establishes habitat absence.
[ ] Bounded NOAA rocky HAPC subset and targeted OSM checks after source/ID review;
    no whole-package bulk acquisition or unqualified licensed/absence claims.
[ ] Production-route integration of reviewed regional audit-only callers is a
    separate code change; current package defaults were not silently replaced.
